# Branding exports

[export.mjs](export.mjs) derives web and native assets from the approved mascot at
`docs/assets/bgo-mascot-organizer.png`. It reuses the API's Sharp dependency and the mobile
Uniwind color parser, resolving native colors from installed HeroUI tokens.

## Run

Install locked workspace dependencies first. From the repository root:

```sh
node scripts/branding/export.mjs --check
```

Check mode compares generated bytes with existing assets without writing files. A mismatch
fails and identifies an asset to regenerate. To overwrite the generated assets:

```sh
node scripts/branding/export.mjs
```

## Outputs and validation

Outputs include mobile launcher/adaptive icons, splash artwork, notification masks,
`branding.json`, web notification assets, favicon frames and Apple touch icons.
The script checks alpha masks, nonempty artwork, crop boundaries and Android adaptive safe zones.

Review the resulting diff and inspect the assets after regeneration. The crop and facial cutouts
are specific to the approved master; replacing it requires reviewing those coordinates.
Native artwork changes require a new binary and device checks. Byte comparisons alone do not
verify native appearance.

See [branding specifications](../../docs/branding.md) for exact output paths, dimensions,
platform constraints and acceptance checks.
